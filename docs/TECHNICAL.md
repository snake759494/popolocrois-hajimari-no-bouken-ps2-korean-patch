# 기술 설명

## 디스크 구성
- 부팅 실행 파일 `SCPS_150.28` (원본 CRC B0258F83 → 한글판 2D5C14EB). `SCPS_150.06/27` 은 사용되지 않는 사본입니다.
- 단일 ISO9660. 크기가 커진 파일은 ISO 끝으로 옮기고 디렉터리 레코드와 볼륨 크기를 고칩니다(`tools/isopatch.py`).

## XPF 아카이브와 LZ 압축 (`xpf.py`, `lz.py`)
- `XPFX`, u32 헤더 크기, u32 항목 수, 항목 32바이트(이름 24, 데이터 기준 오프셋, 크기).
- 항목은 LZ 압축: BE u32 원본 크기 뒤에 플래그 비트(MSB 우선). 0=리터럴, 10+바이트=짧은 거리, 11+바이트+4비트=긴 거리, 길이는 감마식 비트(실행 파일 `0x130800` 해제 루틴 기준).

## 글꼴 FNT (`fnt.py`, `mkfont.py`)
- `G`/`K` 헤더, 레코드 20바이트(폭·메트릭·SJIS 코드·UV), 코드표, 선형 4bpp 아틀라스(높이·폭).
- 폰트마다 쓰는 글자만 들어 있으므로, 한글 음절을 SJIS 한자 코드(0x889F~)에 1:1 배정하고 10종을 모두 다시 만듭니다. 외곽선 색 인덱스·메트릭은 원본 한자 레코드를 따릅니다.

## 텍스트
1. **필드 스크립트 `DATACMN/PP3V*.BIN`** (`pp3v.py`): 워드 단위 바이트코드. `FB52` 뒤에 NUL 종결 SJIS 문자열(4바이트 정렬), `FFFD id` = 라벨 정의, 끝의 라벨표(워드 인덱스)를 문자열 길이 변경 후 재계산합니다. `\n` 줄바꿈, `\c` 다음 페이지.
   - 이 대사 창은 1바이트 문자를 만나면 뒤 글자를 숨기므로, 공백은 2바이트 빈 글리프로, ASCII 는 전각으로 바꿉니다. 2바이트 고정 폭이라 한 줄 17칸·페이지 3줄·106바이트 이내로 맞춥니다(`reflow.py`).
2. **이벤트 자막 EJT**: 텍스트 형식 타임라인. 자막 레코드(`\t17\t…`) 3줄 뒤의 탭 줄이 문장이고 `#N` 이 줄바꿈입니다. `DATAEVT/*/A.EJT` 와 `A??_M.XPF` 안 `a.ejt`(압축) 둘 다 고칩니다.
3. **실행 파일 문자열**: 포인터·코드(lui/addiu) 참조로 찾은 1,090개를 원래 자리에 바이트 상한 안에서 덮어씁니다. `%d` 등 서식과 `\s` 같은 제어 코드는 보존합니다.

## 그림 글자 (`xim.py`, `xcm.py`, `xcmedit.py`, `imgpatch.py`)
- XIM: 헤더 + 팔레트(8bpp 는 PS2 CSM1 순서) + 픽셀(높이, 폭 256, 선형).
- 메뉴 XIM 은 8×8 타일 조각이고, 같은 XPF 의 XCM 이 조립합니다: 뱅크 → 레코드[텍스처 번호, x, y, 타일 크기, 개수, 프레임, uv…]. `xcmedit.py` 가 조립 → 편집 → 타일 재기록을 하며, 여러 곳이 공유하거나 내용이 갈라지는 타일은 빈 칸 또는 텍스처를 늘린 영역에 새로 배정하고 uv 를 고칩니다.
- 지도·튜토리얼·엔딩 등 통짜 이미지는 글자 픽셀을 지우고(OpenCV 인페인팅) 다시 그린 뒤 원래 팔레트로 양자화합니다.

## 와이드 패치
- 필드·이벤트 3D 카메라는 `0x1832E8`·`0x183244` 에서 투영 함수(`0x15A1F8`·`0x15A468`)를 부릅니다. 이 호출을 `0x000FF000` 의 짧은 코드로 돌려 가로 배율 인자(f13)에 0.75 를 곱한 뒤 원래 함수로 넘깁니다.
- 자막 상자·검은 띠를 그리는 2D 카메라는 같은 함수를 다른 곳에서 부르므로 영향받지 않습니다.
