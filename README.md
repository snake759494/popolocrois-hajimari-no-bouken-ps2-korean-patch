# 포포로크로이스 ~시작의 모험~ (PS2) 한글패치

[패치 다운로드](https://github.com/snake759494/popolocrois-hajimari-no-bouken-ps2-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

## 패치 적용 방법

### Windows 에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\PoPoLoCrois - Hajimari no Bouken (Japan).iso'
```

위 표와 다르면 적용을 중단하세요. CHD·CSO 로 변환한 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `PoPoLoCrois_Hajimari_KO_v1.0.xdelta` 를 받습니다.
2. xdelta3 패치를 지원하는 도구(xdeltaUI 등)의 **Apply Patch** 기능을 엽니다.
3. **Patch** 에 xdelta 파일, **Source File** 에 해시가 일치하는 원본 `.iso` 를 선택합니다.
4. **Output File** 에 새 파일명(예: `PoPoLoCrois - Hajimari no Bouken (Korean).iso`)을 지정합니다.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\PoPoLoCrois - Hajimari no Bouken (Japan).iso' '.\PoPoLoCrois_Hajimari_KO_v1.0.xdelta' '.\PoPoLoCrois - Hajimari no Bouken (Korean).iso'
```

## 16:9 와이드 화면 패치 (PCSX2)

`SCPS-15028_2D5C14EB.pnach` 는 v1.0 한글판용 와이드 패치입니다. 저장소의 `widescreen/` 폴더에도 같은 파일이 있습니다.

- 이 게임용 와이드 패치는 PCSX2 내장 패치·공식 패치 저장소에 없어 새로 만들었습니다. 필드·이벤트 3D 카메라가 투영 계산을 부르는 두 곳(EE `0x001832E8`, `0x00183244`)에서 가로 배율을 0.75 배로 줄여 16:9 화면에서도 인물이 늘어나지 않고 좌우 시야가 넓어지게 합니다. 이벤트의 위아래 검은 띠·자막 상자는 화면 전체 폭으로 그대로 그려집니다.
- 코드 조각은 비어 있는 EE 메모리 `0x000FF000` 부근에 둡니다.

> 한글판은 실행 파일이 바뀌어 원본판(CRC **B0258F83**)과 CRC 가 다릅니다(한글판 **2D5C14EB**). 이 pnach 는 한글판 전용이며 원본판에는 적용되지 않습니다.

**적용 방법 (PCSX2 2.x)**
1. `SCPS-15028_2D5C14EB.pnach` 를 내려받습니다. **파일 이름은 바꾸지 마세요.**
2. PCSX2 의 `patches` 폴더에 넣습니다. (`cheats` 폴더가 아닙니다.)
   - 설치판: `문서\PCSX2\patches`
   - 포터블판: PCSX2 실행 파일 옆의 `patches` 폴더
   - 정확한 위치는 PCSX2 **설정 → 폴더**(또는 도구 → 데이터 디렉터리 열기)에서 확인할 수 있습니다.
3. 게임 목록에서 한글판 게임을 **우클릭 → 속성 → 패치** 탭을 엽니다.
4. **Widescreen 16:9** 항목에 체크합니다.
5. 게임을 **새로 부팅**합니다. (세이브스테이트 불러오기로는 적용되지 않을 수 있습니다.)
6. 부팅할 때 "게임 패치가 활성화되었습니다" 알림이 나오면 적용된 것입니다.

**참고**
- 화면 비율은 패치가 자동으로 16:9 로 바꿉니다(`gsaspectratio=16:9`). 그래픽 설정의 화면 비율은 기본값(자동)으로 두세요.
- 패치 탭에 항목이 보이지 않으면 게임 속성의 요약 탭에서 CRC 가 **2D5C14EB** 인지, 파일이 `patches` 폴더에 있는지 확인하세요.
- 메뉴·대사 창·자막 같은 2D 그림과 글자는 가로로 늘어나 보입니다(HUD 보정 없음). 불편하면 패치를 끄면 원래대로 돌아옵니다.
- 실기(PS2 본체)에서는 쓸 수 없습니다(PCSX2 전용).

## 한글화 범위

- 필드 스크립트(PP3V) 대사·조사 메시지 고유 문장 2,196개(등장 5,515회)
- 이벤트 컷신 자막 1,286줄(단독 이벤트 파일과 이벤트 아카이브 안 사본 모두)과 엔딩 크레딧(인명 한글 음차)
- 실행 파일 문자열 1,090개: 아이템·장비·기술·몬스터 이름과 설명, 상점·전투·상태 화면, 메모리 카드·HDD 메시지, 지명, 조작 설명
- 그림 글자: 타이틀 로고 부제(시작의 모험), 지도 14장의 지명·현재지, 메모리 카드 화면(책갈피 열기/기록·캐릭터 이름표), 조작 설명 화면, 「원작 만화 읽는 법」「설치 중지」 배너, 전투 명령 아이콘(공·특·도·도망)·상태 라벨, 정령 아이콘(풍·염·수), 음량 슬라이더, 정령 튜토리얼 창, 엔딩 메시지·「계속……」, 개발 안내문
- 글꼴: 게임 글꼴 10종을 나눔스퀘어네오 ExtraBold 로 다시 만들어 한글 약 1,050자 수록 (원본의 둥근 고딕 + 외곽선 스타일 재현)
- 그대로 둔 것: 타이틀의 영문 메뉴(New game/Continue/Option/Album)·제작사 로고·영문 저작권 표기, 음성·동영상, 개발용 디버그 메시지

- PCSX2 v2.2.0 에서 오프닝 이벤트 자막, 첫 필드(피논의 방) 조사 대사, 메모리 카드 화면, 상태·환경 설정·조작 설명 메뉴, 지도를 확인했습니다. 전투 화면과 중반 이후는 직접 플레이 검수하지 않았으므로 글자 겹침·잘림이 있으면 알려 주세요.
